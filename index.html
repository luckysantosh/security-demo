🔐 Security Check

A convincing login page does not necessarily mean that a website is legitimate.

Before entering sensitive information, verify the website and the reason for the login request.

⚠️ Warning signs

  • Unexpected login request
  • Unfamiliar website address
  • Pressure to act immediately
  • Requests for sensitive information
  • Unusual spelling or formatting
  • Links received from unknown sources
